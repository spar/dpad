dpad installs one program with two names, dpad and the short dp. Run dp on its own for the full-screen terminal UI, or use it in place of docker for everyday commands.

What you need

  • A running Docker engine: Docker Desktop, colima, Docker Engine on Linux, or a remote server.
  • The Docker CLI (docker) on your PATH. dp reads containers, stats and logs through the Docker Engine API, and hands every command it doesn't enhance to docker.

Install

macOS and Linux with Homebrew

$brew install spar/tap/dpad

Upgrade later with brew upgrade dpad.

macOS, Linux or WSL2 without a package manager

$curl -fsSL https://dpad.sh/install | sh

The script picks amd64 or arm64, checks the download against the release's SHA-256 checksum and installs into ~/.local/bin for your user. If your shell can't find dp afterwards, add export PATH="$HOME/.local/bin:$PATH" to your shell profile. Run the same command again to upgrade. dpad.sh/install redirects to scripts/install.sh on GitHub, so you can read it first.

Windows with Scoop

>scoop bucket add spar https://github.com/spar/scoop-bucket; scoop install spar/dpad

Windows with PowerShell

>irm https://dpad.sh/install.ps1 | iex

This installs into %LOCALAPPDATA%\Programs\dpad and adds it to your PATH.

Release archives for every platform, with checksums and signed build provenance, are on the latest release page. Check the install with dp --version.

Open the TUI

$dp

dp connects to the same daemon as docker: it follows DOCKER_HOST, DOCKER_CONTEXT and your current Docker context. There is nothing to configure.

The footer always lists the keys for the selected row, and the mouse works too: click a tab or row, double-click to open, scroll with the wheel. All keys are on Keyboard shortcuts.

Use dp in place of docker

These commands keep Docker's flags and add color and sorting:

$ dp ps -a                # colored states and a health column
$ dp images --sort size   # human sizes and a total
$ dp stats --sort mem     # live stats, biggest memory users first
$ dp logs -f api worker   # Compose services or containers in one stream

Any other command or flag goes to docker unchanged, so dp exec -it web sh and dp ps --format '{{.Names}}' work as you expect. Output stays plain when piped, when NO_COLOR is set, or with --no-color, so scripts keep working.
