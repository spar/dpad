A ctop alternative

Updated 28 November 2026

ctop made a top for containers popular, and it still works for many people. But its last release, v0.7.7, came out on 22 March 2022, and the last commit on its main branch was on 1 August 2022. If you want the same at-a-glance view from a tool that is still changing, here is how dpad lines up.

ctop facts from its README, releases and commit history, checked on 28 November 2026.

The same idea: everything live, one screen

ctop's grid shows CPU, memory, network and disk I/O for every container, with a single-container view on o. In dpad, the closest match is the Stats tab, or the standalone command:

$dp stats

What dpad adds

  • Rates, not totals. Network and disk show bytes per second; t switches to totals.
  • History. Two-minute CPU and memory sparklines with average and peak for the selected container.
  • Compose grouping. Each Compose project collapses into one row with summed CPU, memory and I/O.
  • Logs that follow a project, with a live regex filter (guide).
  • Remote hosts over SSH and Docker contexts (guide).
  • A CLI too. dp ps, dp images, dp stats and dp logs work like Docker's with color and sorting.

What ctop has that dpad doesn't

  • Support for runC containers as well as Docker.
  • A deliberately tiny scope. If all you want is the grid, ctop is simpler, and it is still packaged for Homebrew, MacPorts, Scoop and Arch.
  • Column choices saved to its own config file (c, then S).

Install dpad

$brew install spar/tap/dpad && dp stats
