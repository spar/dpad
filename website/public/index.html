Stop juggling
docker ps, stats and logs.

One screen to rule them all.

dp adds live stats with sparklines, multi-container logs, Compose project controls and a full-screen terminal UI. Anything it doesn't enhance goes straight to docker.

$brew install spar/tap/dpad
>scoop bucket add spar https://github.com/spar/scoop-bucket; scoop install spar/dpad
$curl -fsSL https://dpad.sh/install | sh
>irm https://dpad.sh/install.ps1 | iex

Then run dp. Needs a running Docker engine and the Docker CLI.

dp

Opens the full-screen terminal UI.

dp ps -a

Colored, sortable ps with a health column.

dp stats --sort mem

Live stats, biggest memory users first.

dp logs -f api worker

Services or containers in one stream.

why dp

Keep the commands you know.
Lose the grep pipelines.

docker ps and docker stats are fine for a quick look. Once you run more than a handful of containers, dp fills the gaps, and every other command and flag passes through unchanged.

1 containers tab01 / 04

Every container, live

  • States, health and ports in color.
  • A braille CPU graph and memory on each running container.
  • Start, stop, restart, pause, kill and remove with a confirmation.
  • e opens a shell inside.
3 stats tab02 / 04

Live stats you can read at a glance

  • CPU and memory bars that change color as usage climbs.
  • Network and disk as rates per second; t for totals.
  • Sort by any column with s, reverse with r.
  • Two-minute sparklines with average and peak.
enter logs03 / 04

A whole project's logs in one stream

  • Follow one container, several, or a whole Compose project.
  • Log levels highlighted in plain text, JSON, logfmt and nginx.
  • / filters by regex, including lines still arriving.
  • Follows containers as they scale, restart or get recreated.
4 projects tab04 / 04

Compose projects, start to finish

  • Grouped by project and service, with running and unhealthy counts.
  • u previews and runs pull + up -d.
  • e edits the Compose file, checks it and shows the diff before saving, also over SSH.

Details d

State, exit code, OOM status, restart policy, health checks, ports, networks and mounts.

Events 5

A live timeline of lifecycle and health events, filterable by container, project, service or type.

Prune X

Lists exactly what a prune would remove, then removes only those after y.

Settings o

Theme, Docker context, editor, CPU graph style, icons and mouse, saved to config.yaml.

themes

Eleven built-in themes, or bring your own

The default follows your terminal's own palette. Press C to switch, or add a theme as one YAML file.

install

One command on any platform

Homebrew

macOS and Linux

$ brew install spar/tap/dpad

Install script

macOS and Linux, no package manager. Checks the SHA-256.

$ curl -fsSL https://dpad.sh/install | sh

Scoop

Windows

> scoop bucket add spar https://github.com/spar/scoop-bucket
> scoop install spar/dpad

PowerShell script

Windows, no package manager. Checks the SHA-256.

> irm https://dpad.sh/install.ps1 | iex

The scripts install dpad and dp for your user. Release archives for every platform carry SHA-256 checksums and signed build provenance: latest release.

Try it on your containers

Nothing to configure. dp uses your existing Docker contexts and DOCKER_HOST.

$brew install spar/tap/dpad && dp
