lazydocker alternatives

Updated 28 November 2026

lazydocker is the best known terminal UI for Docker, and for many people it is the right one. If you are looking for something else, these are the open source terminal tools worth a look, with what each does best. This page is written by the dpad project, so we've tried hard to be fair to the others.

Facts come from each project's own README and release notes, checked on 28 November 2026. "Not documented" means we couldn't find it there, not that it can't be done. Corrections are welcome as issues.

dpad

Our own project, so read this one with that in mind. dpad is a full-screen TUI that is also a better docker for everyday commands: dp ps, dp stats and dp logs keep Docker's flags and add color and sorting, and anything else passes through. Its strengths are logs across any mix of services with a live regex filter, stats with per-second rates and two-minute sparklines, and Compose image updates across every project on a host with a preview. It is new (started in November 2026), it has a small community, and it has no Swarm support or image layer view.

dry

dry is the most complete alternative for Docker Swarm, with views for nodes, services and stacks. Its Compose view marks services whose Compose file changed since their containers were created, so you can recreate just those. It has log search, a disk usage view and image and volume cleanup. Its README says it does not read Docker contexts; set DOCKER_HOST or -H instead, including ssh:// addresses.

oxker

oxker is a small, fast Rust viewer for containers: start, stop, pause, restart and delete, log search, and saving a container's logs to a file. Its keymap and colors are configurable. It doesn't document Compose support, and its README says exec is not available on Windows.

dtop

dtop, from the author of the Dozzle log viewer, is built for monitoring several hosts in one table: pass --host more than once, over SSH, TCP or TLS. It streams a container's logs, links to Dozzle, has bulk actions and updates itself. It shows the Compose project of each container but doesn't document Compose actions. The latest release ships for macOS and Linux.

ctop

ctop is a top-style grid of container metrics, with a single-container view and support for runC as well as Docker. It is simple and still widely installed. Its last release was v0.7.7 in March 2022 and the last commit on its main branch was in August 2022. See ctop alternative.

Web UIs instead

If you'd rather use a browser than a terminal, Portainer and Dockge are the usual choices. They run as a container on the host and give you a web dashboard, which suits shared servers and people who don't live in a terminal. That is a different kind of tool, so we haven't compared them here.
