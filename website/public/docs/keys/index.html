Keyboard shortcuts

Updated 28 November 2026

Press ? in any view for the keys that apply there. The footer also lists the keys for the selected row.

Everywhere

KeyAction
tab / shift+tab / 1–7Switch tab: Containers, Images, Stats, Projects, Events, Volumes, Networks
↑ ↓ j k pgup pgdn g GMove
/Filter the current tab (enter keeps it, esc clears it)
s / rNext sort key / reverse
ctrl+rRefresh and check the connection
cChoose a Docker context for this session (list tabs)
CChoose a color theme, previewed live
oSettings: theme, context, editor, CPU graph, host panel, icons, mouse, config file
ISystem: the daemon's host, engine versions, usage and docker system df (guide)
XPreview a prune (guide)
?Help
qQuit

Containers

KeyAction
enterFollow logs
dDetails (esc back)
tShow or hide the host panel
eOpen a shell; type the executable, such as /bin/bash
S / x / RStart (or unpause) / stop / restart, after y/N
P / K / DPause / kill (SIGKILL) / remove, after y/N

Log viewer

KeyAction
/Filter by regular expression (guide)
ctrl+lClear the filter
wWrap long lines
tTimestamps
← →Pan long lines
esc / qBack

Stats

KeyAction
tRates or cumulative totals for network and disk
vCompose projects or a flat list
space / enter on a projectExpand or collapse it

Projects

KeyAction
spaceExpand or collapse a project
enter on a projectFollow the logs of every container in it
S / x / R on a projectPreview, then start / stop / restart its containers
u / UUpdate images for this project / all projects (guide)
e on a projectEdit its Compose file (guide)
D on a projectPreview docker compose down; v also deletes its volumes

Images, events, volumes, networks

KeyAction
d / enterDetails of the selected image, volume or network, or the event's container
x on an imageRemove the selected tag or image, after y
r / g on EventsReverse the order / back to the newest and follow
tab in network detailsSwitch between metadata and endpoints

Mouse

Click a tab or a row to select it, double-click a row to do what enter does, and scroll lists, logs and details with the wheel. While dp has the mouse, selecting text in most terminals needs a modifier: shift on most Linux and Windows terminals, option in iTerm2. Set mouse: false in config.yaml to leave the mouse to the terminal.

Your own keys: custom commands. Full reference: Keys.
